# Demo-website 旅遊攻略網站

一個簡潔實用的旅遊攻略分享平台，專門介紹馬來西亞的旅遊景點、行程規劃與在地美食。

## 📌 專案介紹

本專案提供馬來西亞旅遊攻略資訊，幫助遊客快速了解當地景點、交通、美食等實用資訊。內容以易讀的 HTML 格式呈現，適合旅行前做功課。

## 📂 檔案結構

```
Demo-website/
├── README.md                  # 專案說明文檔
├── 旅遊攻略書.html           # 旅遊攻略完整指南
└── 馬來西亞跟著跑.html       # 馬來西亞旅遊行程推薦
```

## 🎯 主要內容

### 旅遊攻略書

涵蓋馬來西亞旅遊的各項重要資訊：

- 景點介紹與推薦
- 行程規劃建議
- 交通運輸指南
- 美食餐廳推薦
- 住宿選擇
- 實用旅遊貼士

### 馬來西亞跟著跑

精心策劃的旅遊行程推薦：

- 經典路線安排
- 行程時間分配
- 景點停留時間
- 預算參考

## 🚀 快速開始

1. 打開 `旅遊攻略書.html` 查看完整攻略
2. 打開 `馬來西亞跟著跑.html` 了解推薦行程
3. 根據需要規劃您的旅行

## 📱 使用方式

- 在網頁瀏覽器中直接打開 HTML 檔案即可查看
- 無需安裝額外軟體
- 支援所有主流瀏覽器
